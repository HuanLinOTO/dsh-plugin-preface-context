## 行动（按文件）

### Host 半部

- `src/config.ts`：`Config` 改成 `@deepseek-ai/schemastery` 的 `.volatile()` schema（`enabled`/`contextText`）；新增 `PrefaceEntryConfig`（`Volatile<boolean>`/`Volatile<string>`，`apply` 实参）；`resolvePrefaceConfig` 保持返回**纯值**（`.get()` 解引用），保留严格 unknown-key 校验。**RC1-04**；import 由 bare `schemastery` → `@deepseek-ai/schemastery`（只有 fork 带 `.volatile()` 且与 Loader 的 volatile diff 同协议）。
- `src/settings.ts`：删除 `installPrefaceSettings`/`PREFACE_SETTINGS_NAMESPACE`/`PrefaceSettingsBridge`；改为 `installPrefacePage(ctx)` = `ctx.inject(['settings'], child => child.effect(() => child.settings.configure({ auto: false }, ctx.fiber)))`。**RC1-04**。加 `import type {} from '@deepseek-ai/dsh-settings'` 引入 `ctx.settings` Context 合并。
- `src/index.ts`：删 `installPrefaceSettings` 桥；`apply(ctx, config: PrefaceEntryConfig)` 改为订阅 `agent/created`（返回 `undefined`）并在事件时 `config.enabled.get()`/`config.contextText.get()` 读**实时**值；`PLUGIN_SOURCE` 由 `{kind:'plugin', plugin, form}` 改为自声来源 `{kind:'preface-context', form:'instructions'}`（`declare module '@deepseek-ai/dsh-llm' { interface MessageSourceMap { 'preface-context': { kind:'preface-context' } & ContextFormed } }`）。**RC1-07 + RC1-08 副作用**。

### Web Client 半部

- `src/client/index.ts`：`inject` `settingsScope` → `configForms`；`ctx.configForms.get('dsh-plugin-preface-context')` 建 controller；注册 `plugins.row.config`（key `@huanlin/dsh-plugin-preface-context#dsh-plugin-preface-context`，`locale: NS`），经 `ctx.configForms.whileServed([ENTRY_ID], () => ctx.slots.inject('plugins.row.config', …))` 门控。**RC1-27 + RC1-31**。类型 import 由 `dsh-client-ui-settings-plugins/client` → `dsh-client-ui-plugin-manager/client`。
- `src/client/preface-card-controller.ts`：`SettingsScope`/`SettingsScopeSnapshot` → `ConfigForm`/`ConfigFormSnapshot`；`save()` 处理 `set`/`unset` 返回 `boolean`（`false` = Host 拒绝 → `failed` 且保留草稿）。**RC1-27**。
- `src/client/preface-card.tsx`：`PropsRuntime<'plugins.row.config'>`；`view === 'summary'` 返回 `t('description')`；根元素 `<li>` → `<div>`；`IconChevronDownOutline14` → `IconChevronDownOutlineRegular`。**RC1-26 + RC1-31**。

### 配置/构建

- `package.json`：peer + `@deepseek-ai/dsh-*` → `^0.1.7-rc.1`；`dsh-client-ui-settings-plugins` → `dsh-client-ui-plugin-manager`；新增 `@deepseek-ai/dsh-agent` peer；bare `schemastery` → `@deepseek-ai/schemastery`；`dsh.client.inject` 同步换槽。**RC1-01**。
- `tsdown.config.ts`：`HOST_EXTERNALS` `schemastery` → `@deepseek-ai/schemastery`；`CLIENT_EXTERNALS` 换 plugin-manager。
- `tsconfig.json` / `tsconfig.client.json`：`paths` 换 plugin-manager（开发期解析本地 checkout）。
- `pnpm-workspace.yaml`：`minimumReleaseAgeExclude` 由 `@0.1.5-rc.1` → `@0.1.7-rc.1`，补 plugin-manager/dsh-agent。
- `cordis.patch.yml`：注释更新（`agent/created`、`plugins.row.config`、row config 即持久化位置）。
- `AGENTS.md` / `README.md`：技术叙述同步新 API。
